PROMPTS PARA ANIMACIONES DEL PERSONAJE — HELI
================================================
Personaje 2D estilo cómic, fondo verde (chroma key).
Usar en Magnific para generar las animaciones.

---

1. IDLE (Reposo)
Personaje 2D estilo cómic de pie, brazos relajados, respirando suavemente, mirada al frente, fondo verde chroma key, iluminación uniforme, sin sombras duras, animación loop.

2. CORRIENDO (Running)
Personaje 2D estilo cómic corriendo hacia la derecha, brazos y piernas en movimiento, expresión determinada, fondo verde chroma key, animación loop, velocidad constante.

3. SALTO (Jump)
Personaje 2D estilo cómic saltando hacia arriba, brazos abiertos, rodillas dobladas, expresión de esfuerzo, fondo verde chroma key, ciclo completo de salto (agacharse, impulsarse, subir, caer, aterrizar).

4. ATAQUE (Attack)
Personaje 2D estilo cómic lanzando un golpe o ataque hacia la derecha, brazo extendido, expresión de impacto, fondo verde chroma key, animación loop o ciclo único.

5. VOLANDO (Flying)
Personaje 2D estilo cómic volando horizontalmente, brazos extendidos hacia adelante, cuerpo estirado, capa o ropa ondeando, expresión de velocidad, fondo verde chroma key, animación loop.

6. CELEBRACIÓN (Celebrate / Win)
Personaje 2D estilo cómic celebrando, brazos arriba, saltando de alegría, sonrisa grande, fondo verde chroma key, animación loop, energía positiva.

7. DERROTA (Defeat / Lose)
Personaje 2D estilo cómic derrotado, de rodillas o caído, cabeza gacha, expresión triste, fondo verde chroma key, animación loop o ciclo único.

8. RECOGER (Grab / Pick Up)
Personaje 2D estilo cómic agachándose para recoger un objeto del suelo, brazo extendido hacia abajo, expresión concentrada, fondo verde chroma key, ciclo único con vuelta a posición neutral.

9. PENSANDO (Thinking)
Personaje 2D estilo cómic en pose de pensar, mano en la barbilla, mirada hacia arriba, expresión pensativa, fondo verde chroma key, animación loop o con pequeños gestos.

10. SALUDO (Wave / Greeting)
Personaje 2D estilo cómic saludando con la mano derecha, sonrisa amigable, mirada al frente, fondo verde chroma key, animación loop, movimiento de brazo constante.
